# Stichting Voor Elkaar — website

Website van Stichting Voor Elkaar, een buurtinitiatief vanuit Huisartsenpraktijk Wijnhaven (Rotterdam Centrum).

Live: https://voorelkaarstichting.nl

## Wat staat hier

Een statische site van één HTML-bestand met inline CSS, plus de afbeeldingen. Geen build, geen JavaScript-framework.

```
index.html              hoofdpagina
netlify.toml            Netlify configuratie (caching, headers, redirects)
logo.jpg                logo in de header
hero.png                hero banner
foto3.png               buurtbewoners (sectie "Iedereen is van waarde")
foto4.png               twee buurtbewoners aan de Oude Haven (sectie pilot)
ONDERNEMERS_FOTO.png    horecascene (sectie "Voor het lokale bedrijfsleven")
```

## Aanpassen

Open `index.html` in een editor. Tekstwijzigingen, kleuren of layout pas je daar aan. Push naar GitHub en Netlify deployt automatisch binnen een minuut.

## Hosting

Netlify, gekoppeld aan deze GitHub-repo. SSL via Let's Encrypt (automatisch).
